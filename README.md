# Clash of BaNG

Clash of BaNG is a responsive community website developed as a Human-Computer Interaction project.

The website is designed as a futuristic community platform where users can explore troop information, browse galleries, learn about the community, and register as new members.

## Project Overview

The project focuses on combining interface design, responsive web development, and interactive features using HTML, CSS, and JavaScript.

The interface was first designed as a prototype in Figma before being implemented as a functional website.

## Pages

The website consists of five main pages:

- Home
- Gallery
- Troops
- About
- Register

## Features

- Responsive navigation
- Mobile hamburger menu
- Image gallery
- Troop search and filtering
- Carousel
- Parallax effect
- Scroll reveal animations
- Ripple button effects
- Registration form validation
- Responsive desktop, tablet, and mobile layouts

## Technologies

- HTML5
- CSS3
- JavaScript
- Figma
- Google Fonts
